# 🍽️ CraveX – Food Delivery App (UI/UX Design Project)

CraveX is a modern food delivery application designed in Figma with a focus on creating a smooth, intuitive, and visually appealing user experience. This project was developed as part of a team collaboration, where we aimed to simplify the food ordering journey from browsing restaurants to completing an order.

## ✨ Key Features

- Clean and modern user interface
- Easy navigation for a seamless user experience
- Smart search and food discovery features
- Interactive prototype with realistic user flows
- Streamlined cart and checkout process
- Consistent design system across all screens

## 👥 Team Collaboration

This project was completed as a group effort, with team members contributing to:

- User research and requirement analysis
- User journey mapping and wireframing
- UI design and prototyping
- Design reviews and usability improvements

## 🎯 Design Goals

- Create an intuitive and user-friendly experience
- Maintain visual consistency throughout the application
- Improve accessibility and ease of use
- Design a solution that reflects real-world food delivery needs

## 🛠️ Tools Used

- Figma (UI Design & Prototyping)
